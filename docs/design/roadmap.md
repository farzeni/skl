# Roadmap

::: warning Design preview
skl is not built yet. This page describes the planned behavior.
:::

| Version | Scope |
|---|---|
| **v0.1** | `init`, `sync` (conflicts by hand), `use`, `add`, `drop`, `status`, skill sets, `import`, `history`, `rollback`, `--help` and `--version`, and `--json` on `status` and `history` |
| **v0.2** | `learn` copies, updates of unchanged copies and copied skill sets (no Claude), license check, update check in `sync` |
| **v0.3** | First a spike on how skl runs `claude` for an interview. Then lessons, including updates of skills you changed, and sync conflicts resolved with Claude |
| **v0.4** | `open`, project scope, `skl completion bash\|zsh\|fish`, [third-party parts](../thirdparty/): `skl search`, the `npx skills` import source |
